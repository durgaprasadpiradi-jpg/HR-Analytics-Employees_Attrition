# HR Analytics & Employee Attrition Analysis

## Project Overview
This project analyzes employee data using SQL to understand workforce distribution and employee attrition patterns. The analysis explores departments, salaries, overtime, job roles, employee satisfaction, and other factors related to attrition.

## Objectives
- Analyze overall employee attrition.
- Compare attrition across departments and job roles.
- Explore salary, overtime, age, and experience patterns.
- Practice advanced SQL techniques.
- Check selected columns for missing values.

## Tools Used
- SQLite
- DB Browser for SQLite
- SQL

## SQL Concepts
- SELECT, WHERE, GROUP BY, HAVING, and ORDER BY
- Aggregate functions: COUNT, SUM, AVG
- CASE WHEN statements
- Common Table Expressions (CTEs)
- JOINs and subqueries
- Window functions: RANK, LAG, NTILE, and PERCENT_RANK
- Data quality checks

## Key Findings
- Total employees analyzed: 1,470
- Employees who left: 237
- Employees who stayed: 1,233
- Overall attrition rate: 16.12%
- Missing values: 0 in the selected columns checked

## Files
- `hr_analytics.sql` — SQL queries used for the analysis.

## Conclusion
This project demonstrates the use of SQL to analyze workforce data, calculate attrition metrics, and explore patterns across employee groups. The findings can help identify areas for further HR investigation.

## Dataset
IBM HR Analytics Employee Attrition dataset, used for educational and portfolio purposes.
